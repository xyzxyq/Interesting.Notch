# 网易云音乐同步歌词验证

范围：用户要求增加多播放器歌词，随后明确先实现网易云，QQ 音乐和酷狗暂缓。

## 实现

- 移除 ContentView、MusicManager 自动获取及手动选择发布中的三处 Apple Music 限制。
- 保留 Apple Music 原生普通歌词的专用读取逻辑；同步歌词复用 LyricsRepository。
- Now Playing 同源增量更新保留元数据、封面和时钟；来源改变时清除上一播放器的状态，避免跨播放器拼接。
- 设置显示“右侧滚动歌词”和“自动跟随正在播放的应用”，底层设置键保持兼容。

## 验证

- `MultiPlayerLyricsChecks.swift`：来源切换、暂停/恢复/跳转、网易云的零进度＋歌曲开始时间戳、与来源无关的歌词获取、缓存隔离，通过。
- `CompactLyricsChecks.swift`：既有匹配、时间轴、时钟、查询重试与取消检查通过。
- Debug 完整 xcodebuild 成功。使用既有稳定开发签名；验证签名及安装二进制与构建一致。
- 安装路径：`/Users/zxy/Applications/InterestingNotch Development.app`。
- 本机网易云 3.1.9（`com.netease.163music`）实时输出《遇见》、随后《美丽的泡沫》、测试切换后《还是会想你》的歌名、歌手、专辑、时长和时钟。
- 《还是会想你》林达浪，190.1226875 秒：应用自动匹配 LRCLIB，设置显示“同步歌词已就绪 · LRCLIB”。
- 通过网易云原生菜单暂停：系统输出 playing=false / playbackRate=0 / elapsedTime=107.515；灵动岛显示 1:47 与播放按钮。随后恢复播放。
- 清理验证重启产生的重复进程，保留一个新版进程。收起火箭 AX 显示“伪装住这份情绪你不懂有多么累”，随后切到“Shawty, it's so freaking heartache”；截图确认右侧文字、左侧燃油、火箭及边缘效果共存。

## 边界

- QQ 音乐、酷狗未安装和实测，按用户要求暂缓，不声称已完成其专项适配。
- 网易云仍通过 macOS Now Playing 提供元数据，歌词通过缓存、LRCLIB／网易云歌词库或用户导入获取，并非读取网易云窗口中的歌词。
- 《美丽的泡沫》未自动匹配，应用明确显示“未找到匹配的同步歌词”；可使用既有手动选择/导入功能。播放器接入不保证歌词库覆盖所有歌曲和版本。
- 真实暂停/恢复和切歌已验证；跳转在确定性模型检查中验证，未单独执行客户端拖动进度条。
