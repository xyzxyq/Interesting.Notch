# 音乐与空闲状态衔接

- 收起状态共用一个容器：音乐以透明度、0.94→1 缩放及 -6→0 pt 位移入场，退场反向；spring response 0.55、dampingFraction 0.9。
- 容器使用明确宽度，音乐出现/消失时黑色外形及附着边缘效果随宽度连续变化。Codex 运行时保持火箭宽度和单一燃油视图，仅音乐内容进出。
- Reduce Motion 使用 0.18 秒淡入淡出，取消位移及缩放。
- 保留 waitInterval 空闲等待设置。修复旧暂停任务取消后仍执行的问题，避免快速暂停/恢复/暂停提前隐藏音乐。

验证：

1. 完整 Debug xcodebuild 成功；稳定开发签名验证通过；安装脚本验证签名及二进制一致，进程 61861。
2. `python3 scripts/check-music-idle.py` 对实际 MusicManager 方法执行快速暂停/恢复/暂停、等待结束、恢复播放检查，全部通过。以 HEAD 旧实现执行同一检查可复现“Cancelled pause prematurely removed music”失败。
3. 网易云实际播放后，收起火箭 AX/截图显示“在爱情里受伤害”；暂停后短暂保留“终有一天”，随后音乐内容消失，仅保留原位置燃油。测试结束恢复到测试前的暂停状态。
4. 未对中间帧逐帧录制或测量 FPS；实机核对入场/退场状态、歌词恢复、燃油布局，具体动感仍需用户实际观感确认。Codex 未运行时的宽度动画与 Reduce Motion 分支已编译，未切换当前 Codex 任务进行专项实机测试。
