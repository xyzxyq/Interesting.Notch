# 水波拐角平滑与开销验证

> 以下为发布前的开发与验证记录；相关改动纳入 [3.0.9](releases/3.0.9.md)，文中的临时路径和进程状态仅对应当时环境。

## 原因与修改

旧水波把每圈 120 个等周长采样点直接连成折线，拐角分配到的点较少，黑、白、彩色水波均出现明显折角。线条使用 round join 只能圆滑笔画连接，不能消除路径本身的折线。

现在改为闭合的中点二次贝塞尔路径：每个采样点作为控制点，相邻点的中点作为端点，各段连接处及首尾切线连续。曲线不超出采样点的凸包，不使用容易过冲的三次样条。该方式会轻微圆化原来的折线路径，属于本次有意的视觉修正。

- 黑色、白色和彩色水波共用修正，保留颜色、每圈颜色固定、传播速度、强弱响应、描边及内侧遮罩。
- 涟漪同样使用平滑路径，删除每点的两次重复轮廓查询，改为一次顺序取样。
- 水波仍为 120 点、涟漪仍为 180 个独立点；正常装饰帧率 24、低电量 15，歌词保持此前指定的 35/15。
- 同帧各圈复用位移数组；固定空间频率预计算正余弦，再用角度加法组合当前相位。水波位移的三角函数计算从每帧四层合计 960 次减为 4 次，涟漪相应位移计算减为 2 次。复用点数组容量，不增加模糊层、粒子数或定时器。

## 验证

`MusicEdgeChecks.swift` 检查：曲线切线连续及闭合、边界无过冲、三色差异、颜色沿传播过程保持固定、位移公式等价、减少动态效果、强弱响应、遮罩。额外覆盖 220/600 点宽度、0.4/1.6 强度和火箭过渡形状。路径检查容许 SwiftUI 路径元素小于 0.0001 点的坐标舍入。

新增 `MusicEdgeRenderChecks.swift`：同一份生产渲染代码生成 3 个时刻的七种效果，以及三倍放大的四种轮廓效果拐角。修改前后图片已人工检查，黑、白、彩色水波和涟漪的折角明显改善。星尘、流星、光雾三种效果的 9 张 PNG 字节一致。

使用 `swiftc -O -D EDGE_CHECKS` 编译同一渲染驱动与新旧生产源文件；每种效果预热 40 帧，测量 120 帧，7 轮交替执行新旧版本。下表为各轮单帧中位耗时的中位数：

| 效果 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 黑色水波 | 0.0531 ms | 0.0558 ms |
| 白色水波 | 0.0620 ms | 0.0650 ms |
| 彩色水波 | 0.0634 ms | 0.0638 ms |
| 涟漪 | 0.0659 ms | 0.0607 ms |

未修改的星尘、流星、光雾也有 0.0006–0.0017 ms 的测量波动。本次水波额外单帧离屏渲染耗时很小；这些数值不等于实屏帧耗时、进程 CPU 或整机功耗，未据此宣称零能耗影响。
