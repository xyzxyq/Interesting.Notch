# 2026-10-29 · 组件视觉与实现逻辑审查

本轮在现有未提交修改上继续工作，未发布或推送。审查以应用自身的关键状态、资源和数据路径为主；不是对全部第三方依赖、所有系统版本与硬件组合的形式化验证。

## 视觉调整

- 水滴保留深色透镜质感，减弱顶部高光、细化轮廓，避免小尺寸下显得厚重。没有新增模糊或持续动画。
- 卡片从“外卡片—问题卡片—选项”三层包围结构收敛为外卡片与选项两层；使用细边缘、低对比背景及统一暖金选中态。
- 调整标题/问题/辅助文字层级和留白，卡片内容高度 460 → 440 点；底部 Esc 改为轻量键帽提示。忽略仍为顶部独立可见按钮，收起和忽略语义不变。
- 选择“其他”时清空旧选项答案并聚焦输入框，防止不小心提交之前的选择。窗口位置按可见屏幕范围约束，避免在靠下位置触发时超出屏幕。

`check-audit-lifecycle.py` 使用提取的生产方法配合受控摄像头/日历/XPC替身验证时序，并使用实际临时文件服务与分享生命周期类；它不证明真实硬件或外部分享服务全部兼容。`check-codex-interaction.py` 使用生产视图、隔离设置和禁止网络提交的预览。

实际预览检查了新版选项选中、填入答案、发送按钮启用，以及顶部忽略后关闭卡片。水滴/卡片的原有动画帧率未降低，未增加轮询任务。未对本轮重新做可靠的能耗 A/B 测量，不沿用前一轮数据宣称本轮 CPU 或续航收益。

最终通过 Release 构建与本地签名，应用运行于 `~/Applications/InterestingNotch Release.app`，启动前关闭旧主进程。测试输出保存在可清理的 `build/audit-20261029/`。
