# 水滴与交互卡片材质调整

## 实现

- 水滴保留原有轮廓与运动，去掉徽章式内圈；主滴和融合小滴共用上左反射面、冷色下缘回光、暖色灯泡和短柔投影。投影使用径向渐变，不增加 blur/filter。最大体积时投影保留底部透明余量，避免 64×82 画布裁切。
- 卡片采用单层系统 `.regularMaterial`，配合烟灰色调、上缘高光和两层静态外阴影。白底实窗检查后加深底色，避免直接使用材质时文字对比度不足。部署目标仍为 macOS 14，不引入新系统版本分支或依赖。
- 选项采用轻微凸起的明暗面，输入框采用较深的凹入面；选择和输入焦点使用暖色边缘，数字快捷键增加小键帽。没有为每个选项新增材质采样。
- 减少透明度时使用不透明系统底色；增强对比度时提高控件边框可见度。保留原生输入控件、命中区域、键盘逻辑、动画时长与帧率，以及窗口 `animationBehavior = .none`。

## 验证

`check-codex-interaction.py` 通过，包括新增隐藏水滴与最大体积的像素边界检查、首次/缓存展开中间值、展开结束后的短时静置检查，以及已有选择/输入/取消/换行/忽略回归。

`check-codex-card-corners.py` 通过 1×/2× 不透明回退外壳检查；有备份和没有备份的负对照路径均检查过。此测试验证边缘与阴影裁剪，不代表系统材质的真实背景采样。材质、选中状态、输入焦点、水滴投影以及水滴点击打开卡片已在原生预览窗口中使用 CUA 查看。

## 短时 CPU 对照

同一假问题、同一新版水滴、卡片保持打开、不输入；对照仅切换旧/新卡片外观。两次采样前后均通过 AX 确认卡片仍显示。通过 `ps` 累计 CPU 时间差除以实际经过时间计算单核百分比：

| 卡片 | 经过时间 | CPU 时间 | 单核 CPU 占用 |
| --- | ---: | ---: | ---: |
| 旧卡片外观 | 20.203 秒 | 1.34 秒 | 6.63% |
| 新材质外观 | 20.174 秒 | 1.29 秒 | 6.39% |

数据保存于 `build/material-polish/control-cpu.json` 和 `after-cpu.json`。这两个短样本没有观察到卡片材质导致的应用 CPU 增加，但不能把差值解释为可靠的性能提升，也不覆盖水滴新旧绘制成本、WindowServer/GPU 或整机电量。早先一组窗口状态未确认的零占用样本已排除。

没有新增后台计时器、轮询、连续材质动画或降低帧率。完整电池续航及不同桌面内容下的 GPU 合成开销未测量。

Release 构建、本地签名及安装完成，启动后确认仅一个主应用实例，隔离预览已退出。真实请求已用于用户外观复核；审美偏好仍以用户反馈为准。

## 透明度微调

用户认可整体方向，希望卡片更通透。仅将烟灰覆盖层上/中/下三处不透明度从 0.64/0.64/0.72 调低为 0.40/0.44/0.52，系统磨砂材质及文字、控件的不透明度不变。“减少透明度”仍使用不透明底色。此三参数调整未重新测量 CPU/GPU，前表数据对应微调前的版本。

微调版 Release 构建、签名及四角回归通过，安装后仅一个主应用实例。用户通过真实请求卡片复核并确认“现在合适”。
