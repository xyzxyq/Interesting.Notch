# 智能节能

在「设置 → 通用 → 智能节能」开启。默认关闭，保持现有使用方式。

开启后，以下任一条件会自动切换到基础模式：

- Mac 正在使用电池供电；接上电源但暂停充电、充满电，不算电池供电。
- macOS 开启低电量模式。
- 系统报告严重或临界温度状态。

条件全部解除后自动恢复增强功能；也可以关闭此开关立即恢复。状态判断复用电源事件和系统通知，没有增加轮询。无电池或电池信息读取失败不会被当作电池供电。

## 基础模式

保留原有音乐播放控制、封面、普通歌词、刘海展开、日历、电池状态、文件暂存等功能。原有功能的必要交互动画保持可用。

暂停火箭、尾焰、速度线、礼花、音乐边缘动效、紧凑歌词的增强绘制与天气更新，恢复系统原指针。Codex 水滴、拉绳、小鱼、交互卡片和模型/额度栏全部隐藏，卡片快捷键与视觉预览不能绕过节能模式。音乐边缘音频采样需求归零后停止采集，Codex HTTP 状态轮询也暂停。

进入时立即取消正在展开或收起的卡片并释放窗口；不发送回答、不忽略事项、不更改原有功能开关，保留未完成事项和输入草稿。恢复时重新获取真实队列，不自动展开卡片，也不补播暂停期间的过时完成动画。节能期间请直接在 Codex 客户端处理交互请求。

独立 Codex 桥接服务与 Codex 客户端继续运行；本开关控制 Interesting Notch 的增强界面及其附属工作。

## 验证范围

- 真实状态观察代码使用隔离的电源/偏好输入，覆盖电池/接电、充满/暂停充电、低电量、热状态、休眠唤醒、恢复和重复事件去重。
- 受控桥接覆盖暂停轮询、旧响应取消、待办/草稿/忽略记录保留、恢复同步及避免误报完成。
- 原生窗口回归覆盖水滴和拉绳卡片在展开、显示、收起途中切换节能，窗口释放及恢复后的键盘操作。
- 天气取消、晚到定位回调、恢复与偏好保持，以及原有媒体、动效、手势、电池和瞬态提示回归通过。

正常模式帧率没有变更。本轮没有实际拔插电源，也没有测量电池续航或给出整机节电百分比。
