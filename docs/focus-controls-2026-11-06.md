# 二维专注图标、全局快捷键与渲染优化（2026-11-06）

## 行为

- 专注播放的左侧只显示聚焦图标，移除专辑封面和封面徽标。普通音乐模式继续显示封面，展开播放器的封面逻辑不变。右侧保留按分钟更新的专注时长。
- 图标保留四段圆弧和中心圆点，统一纯白填充，移除立体渐变、反光和叠加描边。4.8 秒明暗呼吸使用 Core Animation，优先 15 fps，不增加 SwiftUI 时间轴。减少动态效果、锁屏、休眠、智能节能、展开或隐藏岛体时停止呼吸；移除视图时拆除动画。
- 默认全局快捷键为 ⌃⌥⌘F。使用已有 KeyboardShortcuts 的 key-up 回调切换同一个 Defaults 开关，避免长按反复切换；关闭后沿用原有会话计时清零行为。媒体设置与快捷键设置提供同一快捷键的录制入口，Codex 本地按键录制时也暂停此全局快捷键。

## 减少渲染成本

1. 按文字宽度收窄歌词纹理，保留两侧各 64 点预算供粒子漂移，最大仍为 640×66 点。
2. 缓慢折射按移动速度使用 15–30 Hz，慢速时每帧推进不超过约两点；短句、显现和粒子消散保持 30 Hz。句子开始 0.18 秒增加一次边界通知，使显现结束后可以降低刷新率。播放倍速会影响该预算。
3. 稳定文字及描边渲染成内存图片后复用；阅读只动态绘制折射，消散使用不带描边的字形缓存，粒子生成后再描边。缓存键包含文字、宽度、屏幕缩放、是否含描边及减少透明度，NSCache 配置 8 项、4 MB 成本限额；生成失败回退原始字形路径。缓存不写入磁盘。

## CPU 对照

同一 Apple M5，独立 640×110 点原生窗口，Release 优化编译，每个场景预热 3 秒后统计约 18 秒进程 CPU。前后均包含左侧图标；前版为静态立体图标，后版包含原生呼吸。100% 为一个 CPU 核心。普通歌词场景轮换 4、8、3.5、6 秒的不同长短歌词，句间有 0.6 秒间隔；长句场景为 300 秒持句，用于观察很慢的折射。

| 场景 | 改动前 | 改动后 | 相对变化 |
| --- | ---: | ---: | ---: |
| 长时间持句 | 10.005% | 6.737% | 约降低 32.7% |
| 普通换句、消散与间奏 | 10.490% | 8.460% | 约降低 19.4% |
| 无歌词 / 间奏 | 0.018% | 0.020% | 接近测量噪声，不作优劣判断 |
| 停止的歌词时钟 | 0.008% | 0.009% | 接近测量噪声，不作优劣判断 |

仅降低刷新率与收窄纹理时，普通歌词为 10.319%，改善很小；加入缓存后为 8.460%。以上是一轮短时进程测试，不代表整款应用平均 CPU、GPU/WindowServer 成本或续航提升。当前真实应用的 4 秒 sample 恰处于空闲等待，不能用来证明音乐播放负载降低。

源码基线位于 `build/focus-controls-20261106/baseline/`，原始指标为 `before-metrics.json`、`after-cadence-only-metrics.json`、`after-metrics-run1.json`，均在该任务目录下。复现入口为 `python3 scripts/check-focus-efficiency.py`；基线则传入上述源码目录。最终图标另补了初始路径设置，不改变呼吸时钟。
