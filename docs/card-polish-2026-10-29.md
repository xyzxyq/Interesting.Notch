# 2026-10-29 · 卡片四角、对话元数据与数字反选

## 四角浅色残留

旧代码先画阴影，再使用展开/收起遮罩；完全展开时遮罩成为内容矩形，把圆角外的阴影裁成直角。修复为：圆角内容裁剪 → 展开/收起遮罩 → 合成组 → 阴影 → 原有外围留白。不改变卡片尺寸、锚点、动画曲线或帧率。

`scripts/check-codex-card-corners.py` 从生产源码提取修饰器链，使用旧顺序作失败对照。1×、2× 渲染中，旧版顶部边界透明度跳变为 8/255、底部为 22/255；新版最大跳变分别为 2/255、1/255，低于 4/255 的阈值。独立断言确认外阴影保留。白底渲染复现了截图的浅色矩形残留并确认修复后的平滑阴影。

图像及测量位于 `build/card-polish/`；这是生产外壳渲染测试，不替代全部原生控件与动效呈现检查。

## 所属对话的模型与快速模式

真实卡片逐条使用该请求所属 `hostId + conversationId` 的模型、思考强度与服务层设置，不使用全局任务汇总型号。当前对话的真实 IPC 设置及安装后的桥接读回均为 `gpt-6-astra / ultra / priority`。

桥接新增 `serviceTier` 字段，只接受已验证的 `priority`（快速）、`default`；缺失、删除或未知值为 null。快速模式显示暖色型号文字静态发光和“快速”标识，不从模型名称、思考强度或账户信息猜测，不添加循环动画或轮询。

用户截图为“交互预览”，原有 Astra high 来自写死的演示数据。预览现改为“演示数据 · 非真实对话”，避免冒充当前对话元数据。

## 重复数字反选

重复数字键或鼠标点击同一已选选项会取消选择，清空自动填入的选项文字；之后 Enter 进入自定义输入。方向键保持浏览语义，文字编辑模式保持正常数字输入。已选择时 Enter 直接回复的规则不变。

## 展开时序回归

用户反馈点击后停顿，再整张突现。隔离测试中，展开 modifier 和蒙版路径均有连续中间值，ScreenCaptureKit 单窗口截图也能捕获小圆形、中间展开和完整卡片，尚未稳定复现用户描述的突现，因此不能认定为曲线或 GeometryReader 本身失效。

卡片窗口现在显式设置 `animationBehavior = .none`，避免 AppKit 的默认窗口显示/隐藏动画与 SwiftUI 的自定义展开叠加；保留 0.5 秒展开、原有圆角/阴影顺序及动画帧率。此改动没有新增定时器、轮询或常驻动画。Release 构建、签名与单主进程启动通过后，用户在真实请求水滴上复核并确认“已恢复连续展开”。

`check-codex-interaction.py` 新增首次打开和复用窗口的展开中间状态断言，以及稳定后不再执行展开 modifier 的短时检查；这些断言不等同于屏幕帧率测量。`build/request-reliability/reveal-presentation/` 保存隔离窗口的前后屏幕截图、实际采集时刻和进度记录；截图 API 的延迟在记录中保留，不能把请求时刻误作精确呈现时刻。
