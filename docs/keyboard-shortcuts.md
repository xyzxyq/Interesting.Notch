# 水滴与交互卡片快捷键

设置路径：**设置 → 快捷方式 → 快捷键自定义**。所有配置自动保存，可单独清除或恢复此页默认值。

| 操作 | 默认快捷键 | 生效范围 |
| --- | --- | --- |
| 打开交互卡片 | ⌥⌘Return | 全局，有可见水滴且存在待处理提醒时 |
| 选择选项 | 1–9；0 为第十项 | 当前卡片高亮的提醒，未在输入文字时 |
| 开始输入 / 确认回复 | Return | 当前卡片；未选择选项时先进入输入，已有选择或正在输入且答案有效时提交 |
| 收起卡片 | Esc | 卡片；保留水滴 |
| 忽略当前提醒 | ⌘Delete | 卡片；只隐藏当前高亮提醒 |
| 忽略全部提醒 | ⇧⌘Delete | 卡片；隐藏当前卡片和水滴 |
| 上一条 / 下一条提醒 | ⌃[ / ⌃] | 卡片；切换高亮项并滚动到对应位置 |
| 上一个 / 下一个选项 | ↑ / ↓ | 未在输入文字时；支持超过十项的选项列表 |

主键区和数字小键盘的数字、Return/Enter 均可使用。选择“其他/自定义”类选项会进入文字输入。输入框中的普通数字和方向键保留文字编辑行为，Shift+Return 可换行；正在使用输入法组合文字时，按键先交给输入法，不提交回答。已提交的请求在等待确认期间不能再次提交。

自定义输入框为空时，再按确认键会退出输入并回到选项浏览，不关闭卡片或隐藏提醒；只有空格或换行也视为空。非空但超长的文本保留编辑状态。Shift+Return（含小键盘 Enter）是固定的文字编辑换行键，不能录制为提交、忽略等动作。若旧配置占用了该组合，仅清除冲突项并提示，保留其他自定义与已清空的键位。

在浏览选项时，重复按同一数字键会取消该选项，并清空它自动填入的文字；鼠标重复点击也一样。取消后按 Enter 即进入自定义输入。上下方向键仍用于连续浏览选项，不执行反选；正在输入文字时，重复数字仍是正文。

“忽略”只影响本应用的提醒显示，不会删除 Codex 对话，也不会代替用户回答或批准请求。卡片中不能直接回答的请求仍需在 Codex 中处理。

录制本地快捷键时，点击按键框后按下新组合；再次点击、移开焦点或切换窗口可取消。重复绑定会提示冲突，普通字母/数字不能绑定提交、收起、忽略或切换提醒，以防输入答案时误触。系统和其他应用的全局快捷键仍可能有外部冲突。

实现复用现有 KeyboardShortcuts 管理全局打开键，其余按键通过卡片自己的 NSPanel 事件路径处理，不安装常驻键盘监视器，不新增轮询，也不改变动画帧率。

验证入口：

- `python3 scripts/check-codex-shortcuts.py`：默认映射、小键盘、冲突、安全限制、保存重载与录制状态。
- `python3 scripts/check-codex-interaction.py`：生产卡片及输入行为，独立偏好设置；禁止真实网络提交。
- `python3 scripts/check-codex-polling.py`：原有状态轮询与生命周期回归。
- `./script/build_and_run.sh --release`：先退出旧主应用，再构建、签名并启动当前 Release。

## 焦点回归修复（2026-10-29）

用户实测发现数字选择偶发失效、鼠标选项后输入切换不可靠。上一轮交互测试在打开后额外清空第一响应者，掩盖了真实焦点恢复。现已移除这些测试辅助操作，正常打开与重开时直接检查生产代码的初始焦点。

卡片现在以可接收焦点的 hosting view 作为初始响应者，并明确区分浏览选项与主动编辑。选项、文本草稿及确认处理集中到活动模型，不依赖懒加载列表行是否挂载。鼠标输入框边框不参与命中，移除整行额外点击手势；打开/重开会回到首条提醒与浏览状态。用户确认的语义保持不变：已选选项后 Enter 直接回复；未选中时 Enter 开始自定义输入，输入后 Enter 提交。

加强后的隔离回归覆盖初始/重开焦点、恢复旧文本编辑器、未挂载行的数字操作、选项题自定义输入、选择后修改文本、IME/重复键与提醒生命周期；真实网络提交仍被阻断。CUA 隔离预览观察到打开后数字键选中、鼠标选择另一项后输入框可接受文字修改且选项取消选中；输入法候选窗口仍未进行完整手工检查。

后续补充：生产原生输入控件回归已检查 Enter 进入→空框 Enter 退出→数字选择恢复，以及 Shift+Enter、小键盘 Shift+Enter 在文本绑定中产生真实换行且不提交。多行文本最终使用普通 Enter 进入提交。另检查仅空白文本、超长文本、重复键、输入法 marked-text 分流与旧快捷键冲突迁移。
