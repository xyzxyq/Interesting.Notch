# Interesting Notch 3.0.13 · 启动与 CPU 优化

减少启动时的设置界面构建和持续装饰动画刷新，降低应用进程的 CPU 开销。

## 本次更新

- **设置按需加载**：首次打开设置时才创建窗口与内容，避免启动时重复构建；关闭重开保留当前标签。
- **装饰动画刷新调整**：正常模式的装饰动画由 24 调至 20 fps，未播放音乐时的常驻水波由 15 调至 10 fps；低电量模式分别为 10 和 5 fps。按时间计算的动画速度保持不变，但时间分辨率降低；歌词和展开收起过渡保持原实现。
- **Release 运行入口**：开发脚本支持 `./script/build_and_run.sh --release`，先退出已有主应用，再构建、签名并启动新实例。

## 性能测量

同一台 Apple Silicon Mac、相同设置和 Release 配置下，旧版与优化版交替启动三轮；刘海收起，常驻水波和 Codex 火箭运行，每轮采样约 40 秒：

| 指标（三轮中位数） | 优化前 | 优化后 |
| --- | ---: | ---: |
| 约 10–40 秒稳定期 CPU | 10.81% | 8.69% |
| 启动后前约 10 秒累计 CPU 时间 | 1.45 s | 1.06 s |

稳定期 CPU 降低约 **19.6%**。累计 CPU 时间包含启动后的动画工作，不是应用打开耗时。结果只代表该机器和场景，未测量整机功耗或长期续航；不能将 CPU 降幅等同于省电幅度。[测量口径与原始记录](https://github.com/xyzxyq/Interesting.Notch/blob/v3.0.13/docs/performance-2026-10-23.md)说明了测试条件和限制。

## 安装与升级

在设置中检查更新，或下载 `interesting-notch-3.0.13-arm64.dmg`，退出旧版后将应用拖入 Applications。

Codex 桥接代码与 3.0.12 相同，已安装该版桥接的用户无需重新安装。新用户或使用更早桥接的用户可下载 `interesting-notch-3.0.13-codex-bridge.zip`，解压后执行：

```bash
python3 scripts/codex-notch-bridge-install.py --binary ./codex-notch-bridge
```

支持 Apple Silicon，最低 macOS 14。安装包沿用既有本地开发证书签名，未经过 Apple Developer ID 公证。发布附件包含签名更新源 `appcast.xml` 与 `SHA256SUMS.txt`；应用内更新不会更新独立桥接。

构建、安装包和公开更新通道的验证记录见[发布验证](https://github.com/xyzxyq/Interesting.Notch/blob/main/docs/releases/3.0.13-validation.md)。
