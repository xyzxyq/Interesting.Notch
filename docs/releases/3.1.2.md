# Interesting Notch 3.1.2 · 启动动效与媒体设置

- 首次运行保留 Hello 欢迎动画。常规启动和再次打开应用时，灵动岛会短暂扩张后回落；开启系统「减少动态效果」时使用透明度过渡。主页与暂存器之间增加淡变。
- 媒体设置按「播放与控制、歌词、沉浸专注、动态与外观、Codex 提醒」分为五个子页，保留原有选项和默认值。
- 更新快捷键组件，修复菜单跟踪期间重复处理鼠标事件的问题。减少歌词投影窗口的重复更新，并在专注关闭时跳过用于查找专注播放器的应用枚举。短时诊断尚未证明整体功耗或续航提升。

支持 **Apple Silicon · macOS 14 及以上**。可以在应用内检查更新，或下载 `interesting-notch-3.1.2-arm64.dmg`。安装包沿用本地开发签名，尚未经过 Apple Developer ID 公证；自动更新包另有 Sparkle Ed25519 签名，附件提供 SHA-256 校验清单。

Codex 桥接与 3.1.1 相同，已安装兼容桥接的用户无需重装。首次安装请解压桥接附件并按仓库 README 操作。
