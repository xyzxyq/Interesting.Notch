# Interesting Notch 3.0.10 · Super Rocket 🚀

彩色歌词、更平滑的水波，以及减少重复计算的原生桥接与绘制优化。

## 本次更新

- **歌词字体颜色**：新增自动原配色、自选单色、彩虹渐变，提供设置预览并自动保存。文字与退场粒子共用配色；静态渐变复用缓存绘制，不新增颜色动画定时器。
- **歌词流畅度**：正常模式刷新目标提升至 35 FPS，低电量模式保持 15 FPS；暂停及屏幕休眠沿用既有停帧机制。
- **水波与涟漪**：黑、白、彩色水波的拐角改为连续曲线；复用几何与波形计算，不增加采样点、粒子数或刷新频率。
- **HUD 与充电提示**：统一状态发布与布局过渡，改善音量、亮度、充电、拔电和充满提示的动画衔接。设置中的版本名称同步为 Super Rocket。
- **原生与后台优化**：常驻 Codex 桥接迁移至 Swift；减少无效唤醒、缓存问题投影。应用关闭 Codex 功能或屏幕休眠时暂停状态查询，丢弃取消后迟到的响应；歌词与日月装饰复用固定数据。

README 重新整理了下载入口、功能展示、彩色歌词示例、安装路径与使用指南。

## 安装与升级

1. **应用**：3.0.7 及以后可在设置中检查更新；也可下载 `interesting-notch-3.0.10-arm64.dmg`，退出旧版后拖入 Applications。3.0.6 及更早版本需手动安装。
2. **Codex 桥接**：下载并解压 `interesting-notch-3.0.10-codex-bridge.zip`，在解压目录执行：
   ```bash
   python3 scripts/codex-notch-bridge-install.py --binary ./codex-notch-bridge
   ```
   原生可执行文件已包含在附件内，无需 Xcode 编译；Python 3 仅用于安装。已有 Python 桥接也需执行此步骤迁移，应用更新不会同步替换独立桥接。
3. **颜色**：打开设置 → 媒体 → 滚动歌词字体颜色，选择自选单色或彩虹渐变。

支持 Apple Silicon，最低 macOS 14。安装包使用本地开发签名，未经过 Apple Developer ID 公证。Release 提供 Ed25519 签名的 `appcast.xml` 和 `SHA256SUMS.txt`。
