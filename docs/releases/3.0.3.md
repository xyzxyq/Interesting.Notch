# Interesting Notch 3.0.3

本版仅修复发布安装体验，不改变应用功能。

## 标准拖拽安装包

- DMG 主窗口只显示 `Interesting Notch.app` 和 `Applications` 图标。
- 将应用图标拖到 `Applications`，即可复制到系统 `/Applications` 文件夹；不再要求手动寻找 `~/Applications`。
- 可选 Codex Bridge、安装说明和许可证改为 `interesting-notch-3.0.3-codex-bridge.zip` 独立附件，不干扰应用安装。

## 安装与兼容性

1. 退出正在运行的旧版。
2. 下载并打开 `interesting-notch-3.0.3-arm64.dmg`。
3. 将 `Interesting Notch.app` 拖到 `Applications`。
4. 从 `/Applications/Interesting Notch.app` 启动。

- Apple Silicon，最低部署目标 macOS 14；未提供 Intel 构建。
- 使用持久的本地开发证书签名，未经 Apple Developer ID 公证。首次启动如被系统阻止，请核对来源后使用系统设置提供的“仍要打开”入口。
- 沿用既有 bundle identifier，避免与上游应用同时运行。HUD 需要辅助功能权限，音频响应动画需要录屏与系统录音权限。
