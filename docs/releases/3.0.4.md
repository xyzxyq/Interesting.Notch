# Interesting Notch 3.0.4

## 新增与修复

- Codex 运行任务全部结束后，火箭尾焰熄灭，再播放 1.5 秒完成彩带：分层长飘带、翻转彩纸与细小闪光，沿不同轨迹散开并淡出。
- 修复把“等待用户输入”误当作完成的触发逻辑。只有连续有效连接中的明确空闲状态才触发；断线、状态丢失、关闭模式不会误报。
- 等待交互仍显示原有提醒水滴；移除设置中的火箭、水滴及思考强度预览选项。
- README 新增四组由项目组件生成的循环 GIF，展示火箭完成彩带、液态提醒、音乐边缘与纸飞机指针；明确区分演示与真实录屏。
- Debug 启动脚本改在本机磁盘签名，避免外置盘 AppleDouble 元数据导致签名失败。

## 安装

1. 退出旧版，下载并打开 `interesting-notch-3.0.4-arm64.dmg`。
2. 将 `Interesting Notch.app` 拖到 `Applications`。
3. Codex 用户同时更新桥接：解压 `interesting-notch-3.0.4-codex-bridge.zip`，在解压目录执行 `python3 codex-notch-bridge-install.py`。旧桥接缺少明确空闲字段，不能触发新版完成彩带。

## 兼容性与边界

- Apple Silicon，macOS 14 起；未提供 Intel 包。
- 使用本地开发证书签名，尚未经过 Apple Developer ID 公证。首次启动可能需要在系统设置中核对来源后允许打开。
- Codex 的“完成”表示已确认运行回到空闲，不能区分成功、失败与取消；并行任务全部结束才触发。隐藏或展开刘海、等待交互以及“减少动态效果”会抑制彩带。
- Codex 桥接依赖客户端私有接口；真实端到端时序受客户端与本机状态影响。
- 基于 TheBoredTeam/boring.notch 二次开发，非上游或 OpenAI 官方发行版。GPL-3.0；第三方归属见仓库许可证与声明。
