# Interesting Notch 3.0.13 发布验证

日期：2026-10-24（Asia/Shanghai）。版本 3.0.13，build 313；Apple Silicon arm64，最低 macOS 14。

## 源码与构建

- 优化范围为设置窗口按需创建、持续装饰动画刷新频率及 Release 运行入口。共享服务仍保持原来的提前初始化行为。
- 优化阶段 Debug、Release 构建和八项回归检查通过：设置生命周期、动画／能耗策略、音乐边缘、Codex 轮询与完成反馈、瞬态 HUD、品牌与本地化。版本更新后重新构建 Release，并通过更新源与本地化检查。
- 桥接源码与 3.0.12 相同；本次重新构建 arm64 原生程序，208 项投影与执行路径对照、实际 IPC／HTTP 集成、安装失败回滚检查通过。桥接 ZIP 中十项文件与源码／构建结果逐字节相同，程序与构建脚本保留可执行权限。
- 三轮整应用 CPU 对照及限制见[性能记录](../performance-2026-10-23.md)。这不是整机功耗或续航测量。

## 安装包与实机

- 最终 DMG 通过 `hdiutil verify`，只读挂载核对应用及指向 `/Applications` 的链接，版本、build、bundle ID、arm64 架构及最低系统版本正确。
- 应用内三份许可文件与源码一致；无 AppleDouble 文件，主应用及嵌套代码严格签名验证通过。使用既有本地开发身份，未经过 Apple Developer ID 公证。
- 退出当前主应用后，运行从最终 DMG 提取的副本，同一主 PID 持续运行超过 30 秒。真实界面确认水波、火箭、刘海展开、首次打开设置和关于页版本 3.0.13。
