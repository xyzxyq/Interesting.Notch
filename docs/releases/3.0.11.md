# Interesting Notch 3.0.11 · Super Rocket 🚀

更自然的展开与收起，更连贯的动画衔接，以及新版 Codex 的燃料图标兼容修复。

## 本次更新

- **展开与交互**：调整展开／收起的阻尼与内容缩放，统一按钮、标签和拖放反馈；手势直接跟随输入，结束与取消时回弹，减少重复动画造成的滞后。
- **火箭与提醒**：尾焰、速度线在思考强度切换和暂停恢复时保持运动连续；水滴隐藏时停止持续绘制，低电量模式降低短暂过渡的采样频率。
- **音乐与动画生命周期**：修正滚动标题的溢出测量，快速切换标题时取消旧动画；Lottie 避免重复加载及迟到结果覆盖，暂停播放、屏幕休眠和减少动态效果时停播。低电量模式下频谱上限降至 15 FPS。
- **Codex 燃料图标**：兼容新版 Codex 内置程序路径，修复任务仍在运行、额度却读不到而显示问号的问题。保留原额度刷新频率与过期校验。
- **README**：重新整理功能展示、下载入口、安装步骤、权限和兼容范围，补齐验证记录。

## 安装与升级

1. **应用**：在设置中检查更新，或下载 `interesting-notch-3.0.11-arm64.dmg`，退出旧版后拖入 Applications。3.0.6 及更早版本需手动安装。
2. **Codex 桥接也需要更新**：下载并解压 `interesting-notch-3.0.11-codex-bridge.zip`，在解压目录执行：

   ```bash
   python3 scripts/codex-notch-bridge-install.py --binary ./codex-notch-bridge
   ```

   **仅更新应用无法修复旧桥接的额度读取问题。** 附件包含原生可执行文件，无需 Xcode；Python 3 仅用于安装。安装器保留原配置并在启动失败时回滚。

支持 Apple Silicon，最低 macOS 14。安装包沿用本地开发证书签名，未经过 Apple Developer ID 公证。附件包含 Ed25519 签名的 `appcast.xml` 和 `SHA256SUMS.txt`。

## 验证范围

用户已实机确认自然收起及快速移入／移出的反向切换正常。燃料图标恢复后，跨一次自动刷新持续正常显示。详细构建、回归和安装包检查见[发布验证](3.0.11-validation.md)。

本轮没有提高持续动画刷新频率，也没有新增常驻动画计时器；未进行严格的整机功耗 A/B 测量，不承诺固定 CPU 降幅或续航提升。
