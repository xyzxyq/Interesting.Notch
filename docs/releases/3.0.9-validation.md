# 3.0.9 发布验证

验证日期：2026-09-20。应用版本 3.0.9，build 309；Release 标识 `theboringteam.boringnotch`，arm64，最低 macOS 14。

## 应用与桥接检查

- Debug / Release 构建通过，复用本地 Swift Package Manager 依赖缓存。
- `check-transient.py`：HUD 原子发布、替换与旧计时器取消，音乐/HUD/电池布局，充电、充满、拔电、暂停充电与低电量状态通过。
- `check-energy.py`、`check-music-idle.py`、`check-codex-polling.py`：计时器生命周期、媒体优先级、暂停恢复、屏幕休眠、旧响应丢弃和单查询循环通过。
- `check-native-bridge.py`：183 组 Swift / Python 投影行为对照通过。针对本次发布的实际 Swift 二进制运行 `check-native-bridge-integration.py`，分片 IPC、修订缺口、额度、隐私、鉴权、重复回答、拒绝重试、远程回答、重连及安装失败回滚均通过。测试使用隔离环境，不向真实用户任务发送回答。
- `BrandLocalizationChecks.py`、`check-release-updates.py`：品牌、简体中文、更新源隔离及用户选择自动安装的检查通过。

## 视觉与文档

- `CompactLyricsChecks.swift`：原有歌词匹配、暂停、定位、曲终、日夜及天气检查通过；新增默认、自选单色和彩虹的当前句、退场文字及粒子检查。非歌词区域像素保持一致，默认模式四组预览 PNG 与修改前字节一致。
- `MusicEdgeChecks.swift`：七种效果、三种水波配色、曲线闭合及切线连续、遮罩、减少动态效果、35/15 FPS 歌词配置与 24/15 FPS 装饰配置通过。
- README 四组 GIF 从当前生产组件重新生成，彩色歌词 PNG 来自生产渲染检查；均为演示状态，不是桌面录屏。GitHub Markdown 渲染接口返回完整 HTML，本地文档与图片路径检查通过。
- 本轮彩色歌词离屏绘制单次中位耗时：自动 0.114 ms、单色 0.115 ms、彩虹 0.119 ms。该数据不是屏幕帧率、整机 CPU 或能耗测量。

## 发布附件

- `interesting-notch-3.0.9-arm64.dmg`：Release 应用使用稳定本地开发证书签名，嵌套代码严格签名验证通过；DMG 校验和通过，并以只读方式挂载验证应用和指向 `/Applications` 的拖拽目标。
- `interesting-notch-3.0.9-codex-bridge.zip`：包含实际通过通信测试的 arm64 Swift 二进制、安装器、构建脚本、Swift 源码及 Python 回退代码。归档内容与源文件逐字节比对通过，可执行权限保留，不含 AppleDouble 元数据。
- `appcast.xml`：指向本仓库 v3.0.9 DMG，版本、build、长度与归档匹配；Sparkle 与独立 CryptoKit Ed25519 签名验证通过。
- `SHA256SUMS.txt`：记录 DMG、桥接 ZIP 与 appcast 的 SHA-256，供下载后核对。

安装包及桥接未经 Apple Developer ID 公证。真实自动更新安装/重启、所有播放器及实际整机功耗不在本次验证范围内；没有以离屏基准承诺固定 CPU 或续航改善。保持本机仅运行 Debug 主应用，不为发布验证额外启动正式版。
