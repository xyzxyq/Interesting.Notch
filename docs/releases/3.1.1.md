# Interesting Notch 3.1.1 · 专注动效与效率

专注模式增加开关动画和全局快捷键，统一二维呼吸图标与计时，并完善歌词、间奏与封面的表现。

## 专注体验

- 默认使用 **⌃⌥⌘F（Control + Option + Command + F）** 切换专注模式，可在媒体或快捷键设置中修改。
- 开启时 0.42 秒轻微聚拢、淡入；关闭时 0.28 秒收拢、淡出。快速反向切换保持连贯，系统“减少动态效果”下使用 0.12 秒淡变。
- 音乐播放与暂停时均显示二维聚焦图标和累计时长，聚焦图标轻柔呼吸，不再显示专辑封面。
- V 字玻璃投影在音乐播放期间持续保留，换句时由出光口向歌词扩散弧形光脉冲。
- 无歌词或间奏时，三个纯黑粒子交错换位，与光晕联动；歌词句末化为更细小的多色粒子。专注投影统一使用粒子样式。

## 可靠性与效率

- 改善 Apple Music 原生封面暂缺、目录 ID 延迟到达和地区查询失败时的恢复；严格核对曲目身份，避免使用其他歌曲的封面。
- 缓存歌词字形与文字宽度，缩小逐帧渲染范围，按歌词边界调度更新；等待动画与图标呼吸使用原生合成层。
- 本机 Apple M5 的同一歌词片段短时对照中，进一步优化后应用 CPU 从 **9.60% 降至 6.60%**。最终构建的无歌词、暂停平均 CPU 分别为 **0.36%、0.41%**。这是特定机器和片段的结果，不是所有歌曲的性能保证。
- 同一对照的整机传感器功耗为 **13.08 → 13.20 W**，未证明续航或整机节能改善。[测量方法与排除样本](https://github.com/xyzxyq/Interesting.Notch/blob/v3.1.1/docs/focus-transition-power-2026-11-06.md)。

歌词投影仍仅在**专注开启、音乐播放、接通外部电源**时显示；锁屏、休眠、节能生效或展开灵动岛时收起。

## 安装与升级

支持 **Apple Silicon · macOS 14 及以上**。可在应用设置中检查更新，或下载 `interesting-notch-3.1.1-arm64.dmg`。

**Codex 桥接与 3.0.14、3.0.15、3.1.0 相同，已有这些版本桥接的用户无需重装。** 首次安装可解压 `interesting-notch-3.1.1-codex-bridge.zip` 并执行：

```bash
python3 scripts/codex-notch-bridge-install.py --binary ./codex-notch-bridge
```

安装包沿用本地开发证书签名，**尚未经过 Apple Developer ID 公证**。附件提供 `SHA256SUMS.txt`，自动更新包另经 Ed25519 签名验证。未覆盖 Intel、全部系统／显示器组合及长时间续航测试。
