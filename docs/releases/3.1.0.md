# Interesting Notch 3.1.0 · 沉浸专注

新增「沉浸专注」模式：在 **设置 → 媒体 → 沉浸专注** 开启，让音乐和一句歌词留在灵动岛附近。默认关闭。

## 单句歌词投影

- 小范围 V 形玻璃光影从岛底延伸，内部逐渐透明，中央接缝柔和过渡；歌词没有黑色底板。
- 中性白色字面配细轮廓，采用系统字体；一道较窄的折射波从左向右流过，每句速度随歌词时间变化，经过后文字保持完整。
- 提供微光、粒子、水波三种样式。粒子样式在歌词时间线标记的句末开始消散。
- 动效使用 Metal GPU 渲染，最高约 30 fps。系统「减少动态效果」使用静态展示；「减少透明度」关闭玻璃材质并保留可读字形。

投影仅在**专注已开启、音乐正在播放、接通外部电源**时显示；休眠、锁屏、智能节能生效或展开灵动岛时收起。GPU 加速不等同于低功耗，未承诺电池续航收益。

## 专注状态与媒体独占

- 无音乐播放时，左侧显示圆润的「聚焦」图标，右侧显示累计时长，例如 `15 MIN`、`1.5 h`。岛体与音乐播放时等宽，计时每分钟更新。
- 播放音乐恢复专辑封面，计时继续；暂停恢复专注待机，关闭专注后重置。会话起点在重启后保留。
- 专注期间隐藏其他媒体、火箭、Codex 提醒与完成动画；待处理请求和输入草稿保留，可直接在 Codex 处理。
- Apple Music、Spotify、YouTube Music 桌面客户端独立跟踪音乐，防止其他视频或音频接管系统媒体后替换封面、打断歌词。QQ 音乐和网易云仍依赖系统媒体来源，尚无同等的独立跟踪保证。

## Apple Music 封面修复

按当前曲目身份处理封面，阻止旧曲目的异步结果覆盖新歌；同曲目的短暂空数据不会抹掉已有封面。原生封面缺失时，通过 Apple 目录严格匹配补取，存在歧义时保持留空，避免显示错误专辑。

## 安装与升级

支持 **Apple Silicon · macOS 14 及以上**。可在设置中检查更新，或下载 `interesting-notch-3.1.0-arm64.dmg`。

**桥接与 3.0.14、3.0.15 相同，已有用户无需重装桥接。** 首次使用 Codex 桥接时，解压 `interesting-notch-3.1.0-codex-bridge.zip`，在解压目录执行：

```bash
python3 scripts/codex-notch-bridge-install.py --binary ./codex-notch-bridge
```

安装包沿用本地开发证书签名，**尚未经过 Apple Developer ID 公证**。首次打开被 macOS 阻止时，请核对下载来源后使用系统的「仍要打开」入口。附件提供 `SHA256SUMS.txt`，自动更新包另经 Ed25519 签名验证。

尚未完成所有播放器、多显示器和长期 CPU/GPU/内存验收；逐行 LRC 的句末标记不一定等于实际人声结束时刻。

[发布验证记录](https://github.com/xyzxyq/Interesting.Notch/blob/main/docs/releases/3.1.0-validation.md)包含公开下载、3.0.15 → 3.1.0 自动升级，以及旧版同样复现的宿主视图释放检查未通过项。
