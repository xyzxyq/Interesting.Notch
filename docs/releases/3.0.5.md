# Interesting Notch 3.0.5

## 更新内容

- 提醒水滴采用柔和暗色立体质感，高光、轮廓及灯泡随提醒数量一致缩放；修复展开刘海时底部裁剪和快速悬停时的动画跳变。
- 提醒卡片加入液滴舒展式展开、向水滴汇聚的渐进消散、平滑列表收拢；改进深色材质、底部装饰及细滚动条。
- 每项提醒新增低亮度红色删除图标，长选项完整换行；清空提醒与收起按钮并排排列。删除和清空只隐藏本地提醒，不删除或回答 Codex 中的问题。
- 火箭头与尾翼增加轻微弧度和柔光；运行中的火箭可与提醒水滴同时显示，旧提醒不再阻止火箭或完成彩带。
- 完成判定依据持续有效连接下运行任务全部进入明确空闲状态；保留旧提醒时也能触发，断线和等待输入不会误报。
- 音乐开始时的传送门不再瞬移越过刘海；两侧保留原速，刘海遮挡区以两倍速度通过，缩短等待。
- 包含 3.0.4 发布后的提醒面板崩溃与鼠标点击穿透修复。

## 安装

1. 退出旧版，下载并打开 `interesting-notch-3.0.5-arm64.dmg`，将应用拖到 `Applications`。
2. 使用 Codex 联动时，同时更新桥接：解压 `interesting-notch-3.0.5-codex-bridge.zip`，在解压目录执行 `python3 codex-notch-bridge-install.py`。本版桥接修复了保留旧提醒时的空闲状态报告，应用和桥接均需更新。
3. 下载附件可使用 `SHA256SUMS.txt` 核对完整性。

## 兼容性与边界

- Apple Silicon，macOS 14 起；未提供 Intel 包。
- 使用本地开发证书签名，尚未经过 Apple Developer ID 公证。首次启动可能需要在系统设置中核对来源后允许打开。
- Codex 完成表示运行回到明确空闲，不能区分成功、失败与取消；并行运行任务全部结束才触发。展开或隐藏刘海，以及“减少动态效果”会抑制彩带。
- 桥接依赖 Codex 客户端私有接口，兼容性受客户端版本影响。
- 基于 TheBoredTeam/boring.notch 二次开发，非上游或 OpenAI 官方发行版。GPL-3.0；第三方归属见仓库许可证与声明。
