# Interesting Notch 3.0.8

修复切换歌曲时专辑封面可能停留在上一首的问题。

## 修复内容

- 媒体事件先按字节拼接完整 JSON 行，再解码，避免中文字符跨管道分块时丢失歌曲信息和封面更新。
- 将封面清空识别为有效变化；无封面时显示播放器图标或默认图，避免残留旧封面。
- 新增回归检查，覆盖中文 UTF-8 分块、多行事件、切歌后清空旧封面及大封面延迟到达。

## 安装与升级

1. 3.0.7 用户可在设置中检查更新；3.0.6 及更早版本需手动安装。
2. 手动安装：退出旧版，打开 `interesting-notch-3.0.8-arm64.dmg`，将应用拖到 `Applications`。
3. 可选附件 `interesting-notch-3.0.8-codex-bridge.zip` 的桥接代码未变化，已安装的用户无需重装。

支持 Apple Silicon，最低 macOS 14。本包沿用本地开发签名，未经过 Apple 公证。Release 包含 Ed25519 签名的 `appcast.xml` 与 `SHA256SUMS.txt`。
