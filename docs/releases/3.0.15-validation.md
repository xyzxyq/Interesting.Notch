# Interesting Notch 3.0.15 发布验证

日期：2026-10-31（Asia/Shanghai）。版本 3.0.15，build 315；Apple Silicon arm64，最低 macOS 14。

## 功能与回归

- 发布内容为「智能节能」：默认关闭；开启后，在电池供电、系统低电量模式或严重/临界热状态下回退基础功能。正常模式帧率与 3.0.14 一致。
- 功能实现阶段通过原生水滴/拉绳卡片在展开、显示、收起途中进入节能的回归，以及原有键盘、输入、手势、媒体、电池、天气取消/恢复和资源生命周期检查。
- 发布阶段重新通过真实观察逻辑的隔离电源/偏好输入回归、受控 Codex 轮询暂停/恢复与旧响应取消回归、更新配置检查；Release 构建通过。
- 未进行物理拔插电源或电池续航对照，不给出整机节电百分比；独立桥接与 Codex 客户端继续运行。[行为和边界](../smart-energy.md)

## 公开发布与升级

- 源码提交 `47cc226` 与 `v3.0.15` 标签已推送。四个附件先上传草稿，GitHub 返回的大小与 SHA-256 全部匹配本地后，发布为最新正式版。
- `releases/latest/download/` 下的 DMG、桥接 ZIP、appcast 和 SHA256SUMS 均匿名下载成功，与本地逐字节相同。公开下载后的 DMG 再次通过独立 CryptoKit Ed25519 验签。
- 使用此前匿名下载、并与本轮 GitHub 返回摘要重新核对的公开 3.0.14 DMG，提取隔离升级副本；没有覆盖 `/Applications` 的原安装。
- 关闭其他主应用后，用上游 `sparkle-cli` 读取旧副本自身的公开更新源；没有覆盖 feed URL，也没有请求修改自动检查选择。探测、下载、解压、安装均成功，旧进程退出后自动重启为 3.0.15 / 315。
- 升级后新 PID 与旧 PID 不同，只有一个主进程；主程序及 Info.plist 与最终 DMG 逐字节相同，严格嵌套签名通过。
- 隔离升级结束后，已恢复日常安装的 3.0.15 Release；确认单主进程、不带测试参数、程序与发布安装包一致。

原始公开下载、升级日志与结构化检查结果位于可清理目录 `build/releases/3.0.15/`。

## 验证边界

本轮未重新人工复测全部界面，也未覆盖 Intel、所有多显示器组合或长时间续航。原生窗口回归与实际更新工具测试，不等同于人工点击设置页面走完整条操作链路。
