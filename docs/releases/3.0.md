# 3.0 · Super Rocket

基于 [TheBoredTeam/boring.notch](https://github.com/TheBoredTeam/boring.notch) 二次开发的 interesting botch。本版本不是上游或 OpenAI 官方发行版。

## 更新内容

- 新增实验性黑色纸飞机指针：圆滑尖角、立体折面与 75%–175% 大小调节，支持关闭和异常退出后的恢复。
- Codex 火箭对接实际执行状态，修复异步问题存在时火箭不出现的问题，保留思考强度、模型与额度展示。
- 水滴面板直接呈现异步问题与选项，支持点击作答或输入文字回车提交；多行输入自动增高，修复输入框焦点描边裁切。
- 面板通过粒子聚集展开、粒子消散关闭；回答确认后减少提醒，队列清空时水滴沿诞生动画反向回到灵动岛。收起保留问题，清空只隐藏本地提醒。
- 修复 HUD 辅助功能设置入口与授权状态同步，分离 Preview 测试版身份；改善无歌词时的灵动岛边缘、火箭顶部与视频播放状态判断。

## 安装与兼容性

下载 `interesting-botch-3.0-arm64.dmg`，退出旧版后，将 `interesting botch.app` 拖入 Applications。

- Apple Silicon（M 系列芯片），最低部署目标 macOS 14；未提供 Intel 包。
- 使用持久的本地开发证书签名，**未经 Apple Developer ID 公证**。首次打开可能被系统阻止；核对来源后使用系统提供的“仍要打开”入口。
- 正式版沿用既有 bundle identifier；避免与上游原版同时运行。Preview 测试版使用独立标识，系统权限需要分别授予实际安装的应用。
- HUD 需要辅助功能权限；音频强弱动效需要录屏与系统录音权限。
- DMG 附带可选 `Codex Bridge`、安装说明和许可证。桥接需要本机 Python 3 与已登录的 Codex；更新应用后也需运行附带的桥接安装脚本以更新服务。

Codex 直接回复依赖客户端私有接口；失败会保留提醒，需要完整核对的批准类请求仍在 Codex 中处理。纸飞机使用私有 WindowServer 接口，系统自定义指针颜色或应用自定义光标可能影响效果，不保证所有 macOS 版本和应用都兼容。
