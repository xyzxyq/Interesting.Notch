# Interesting Notch 3.0.12 · Super Rocket 🚀

修复 Codex 使用期间频繁出现的问号、丢失的结束彩带，以及后台任务识别问题。

## 本次更新

- **燃料图标**：短暂额度读取失败不再清空仍然有效的读数，任务连接与额度分别更新；保留原始时间戳、150 秒有效期及重置时间校验。额度确实不可用时显示灰色燃料图标，悬浮说明仍提示额度暂不可用。
- **结束彩带**：灵动岛展开或 HUD 占用时延后播放，只在彩带开始发射时标记结束事件已处理。动画准备阶段被取消时可恢复播放，已发射的事件不会重复；保留先熄灭尾焰、再播放 1.5 秒彩带的顺序。
- **后台任务**：单个任务状态超时只影响该任务，不再隐藏其他任务。桥接启动时读取 Codex 桌面已有的任务与主机映射，发现已经运行中的已知远程任务。
- **调试启动**：启动脚本先退出正式版和其他调试副本，再启动新实例，验证主应用进程恰好一个。

## 安装与升级

1. **应用**：在设置中检查更新，或下载 `interesting-notch-3.0.12-arm64.dmg`，退出旧版后拖入 Applications。
2. **同时更新 Codex 桥接**：下载并解压 `interesting-notch-3.0.12-codex-bridge.zip`，在解压目录执行：

   ```bash
   python3 scripts/codex-notch-bridge-install.py --binary ./codex-notch-bridge
   ```

   **应用内更新不会更新独立桥接。** 后台任务发现、超时隔离和桥接侧额度保留需要新版桥接；附件包含 arm64 原生可执行文件，无需 Xcode。安装器保留旧配置，并在启动失败时回滚。

支持 Apple Silicon，最低 macOS 14。安装包使用既有本地开发证书签名，未经过 Apple Developer ID 公证。发布附件包含签名更新源 `appcast.xml` 和 `SHA256SUMS.txt`。

## 验证范围

208 项检查、桥接集成检查、额度与轮询检查、彩带取消及延后播放检查通过。真实界面确认燃料图标和运行尾焰；短时现场观察覆盖一次自动额度刷新。构建、安装包与公开更新通道的检查见[发布验证](3.0.12-validation.md)。

结束仍以新鲜、连续连接下的明确空闲为依据，任务消失或连接丢失不算完成。减少动态效果时不播放彩带；长期连续使用及真实长任务结束的人工视觉验收不在本轮验证范围内。
