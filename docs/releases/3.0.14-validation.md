# Interesting Notch 3.0.14 发布验证

日期：2026-10-31（Asia/Shanghai）。版本 3.0.14，build 314；Apple Silicon arm64，最低 macOS 14。

## 源码与回归

- 当前累计改进与版本号提交为 `c72577f`，已推送至 `main`；本次没有降低现有组件帧率。
- Release 构建、更新配置、锁屏启动、Codex 轮询、音乐空闲、快捷键及资源生命周期检查通过。
- 原生桥接重新构建：334 项原生/Python 投影与执行路径对照、IPC/HTTP 实际集成、重连、重复提交、安装回滚等检查通过。

- DMG 通过 `hdiutil verify`、只读挂载、应用版本与 build 检查；根目录包含应用和指向 `/Applications` 的符号链接。
- 严格嵌套签名通过，应用内无 AppleDouble 文件。打包带入主许可证、第三方许可与说明、MPL-2.0 全文，四份文件与源码一致；日常构建入口也补齐这些资源。

- 沿用既有本地开发证书；未经过 Apple Developer ID 公证。

- `v3.0.14` 标签指向源码及签名更新源提交 `9830fc3`，标签和源码均已推送；四附件通过草稿远端摘要核对后，发布为 GitHub 最新正式版。
- `releases/latest/download/` 下的 DMG、桥接 ZIP、appcast 和 SHA256SUMS 均匿名下载成功，内容与本地逐字节相同；下载后的 DMG 又通过独立 CryptoKit Ed25519 验签。
- 从公开 3.0.13 DMG 提取隔离副本，先核对原版本公开 SHA-256，再执行更新，没有覆盖 `/Applications` 的原安装。
- 先关闭其他主应用，再用上游 `sparkle-cli` 驱动旧副本读取自身公开 feed。没有覆盖更新地址，也没有传入修改自动检查选择的参数。探测、下载、解压、安装均成功；3.0.13 / 313 的旧进程退出，新进程自动重启为 3.0.14 / 314。
