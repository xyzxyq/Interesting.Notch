# Interesting Notch 3.0.7

本版减少媒体播放与静置时的重复后台工作，并启用 GitHub Release 自动更新。

## 更新内容

- 按媒体来源、屏幕休眠状态和实际显示需求启停轮询与音频计量，减少无效唤醒和重复状态发布。
- 优化封面解码和内存使用；暂停时停止不必要的歌词、进度与频谱刷新，修复动画计时器生命周期。
- 缓存歌词字形宽度、跳过透明星形绘制，保留现有动画效果与播放功能。
- 设置 → 关于新增自动检查与自动下载安装选项。默认每天检查，自动安装默认关闭，也可手动检查。
- Release 提供 Ed25519 签名的 appcast.xml，校验更新包来源及完整性。

Apple Music Debug 实播两轮各 60 秒的平均 CPU 为 9.47% / 9.24%；曲目与进度不同，这些观察不能证明固定比例的性能提升，也不代表电池能耗测量。

## 安装与升级

1. 3.0.6 及更早版本需手动安装一次：退出旧版，打开 `interesting-notch-3.0.7-arm64.dmg`，将应用拖到 `Applications`。
2. 3.0.7 起可使用设置中的自动更新。自动安装为可选项，安装在退出应用或确认重启时完成。
3. Codex 桥接附件为 `interesting-notch-3.0.7-codex-bridge.zip`；桥接代码未变化，已安装 3.0.5/3.0.6 桥接的用户无需重装。

支持 Apple Silicon，最低 macOS 14。本包沿用本地开发签名，未经过 Apple 公证；Sparkle 更新签名与 Apple 公证是不同验证机制。校验值见 `SHA256SUMS.txt`。
