# Interesting Notch 3.0.6

## 更新内容

- 修复外接显示器设为主屏时，HUD 无法调节内置屏幕亮度的问题。优先选择可调节的内置屏幕；无可用内屏时，选择支持现有原生亮度接口的活动屏幕。读取或写入失败时不再显示虚假的键盘调节结果。
- 系统媒体模式下，Apple Music 提供歌曲目录 ID 时，从苹果目录获取对应的中文歌曲名、歌手名和专辑名；中文简繁体跟随系统语言。网络失败、目录无匹配或缺少 ID 时保留播放器原文，不进行模糊搜索或猜译。
- 修复音乐播放时切换为 Codex 火箭状态，专辑封面被额度仪表替换的问题。音乐界面保留封面，无音乐时才显示额度仪表；额度暂不可用的问号不再占据播放中的封面位置。

## 安装

1. 退出旧版，打开 `interesting-notch-3.0.6-arm64.dmg`，将应用拖到 `Applications`。
2. 首次使用 Codex 联动时，解压 `interesting-notch-3.0.6-codex-bridge.zip`，执行 `python3 codex-notch-bridge-install.py`。桥接代码与 3.0.5 一致，已安装该版桥接的用户无需重复更新。
3. 可使用 `SHA256SUMS.txt` 核对附件完整性。

## 兼容性与已知限制

- Apple Silicon，macOS 14 起；未提供 Intel 包。
- 使用本地开发证书签名，未经过 Apple Developer ID 公证。
- 不包含普通外接显示器的 DDC 亮度控制；本次修复主要解决主屏切换导致内屏无法调节的问题。
- 中文目录名称获取适用于系统媒体模式下提供有效歌曲 ID 的 Apple Music；不修改 Apple Music 资料库或播放音频。
- Codex 彩带仅在运行任务全部明确进入空闲、连接连续且刘海可显示动画时触发。展开刘海、HUD 占用或减少动态效果会抑制彩带；展开期间收到的完成事件目前不会补播，本版未修改这一行为。
- 基于 TheBoredTeam/boring.notch 二次开发，非上游或 OpenAI 官方发行版。GPL-3.0；第三方归属见仓库许可证与声明。
