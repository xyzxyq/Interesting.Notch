# Interesting Notch 3.0.2

本版集中优化动画计算开销、统一 Interesting Notch 品牌，并补齐简体中文设置。

## 更新内容

- 装饰动画采用正常模式 24 帧、低电量模式 15 帧的刷新节奏；歌词保留正常模式 30 帧，低电量模式 15 帧，并在系统暂停状态停止刷新。
- 波浪轮廓采样由 240 点调整为 120 点，复用位置与法线计算，减少重复路径计算。
- 应用名称、菜单、设置窗口和引导界面统一为 Interesting Notch，保留既有设置标识以兼容已有配置。
- 补齐简体中文设置标题、选项、说明和测试版徽标；语言沿用系统选择。产品名、服务名及必要的技术名称保留原文。

## 安装与兼容性

下载 `interesting-notch-3.0.2-arm64.dmg`，退出旧版后，将 `Interesting Notch.app` 放入 `/Users/你的用户名/Applications`。此电脑的开发应用目录为 `/Users/zxy/Applications`。

- Apple Silicon，最低部署目标 macOS 14；未提供 Intel 构建。
- 使用持久的本地开发证书签名，未经 Apple Developer ID 公证。首次启动如被系统阻止，请核对来源后使用系统设置提供的“仍要打开”入口。
- 沿用原有 bundle identifier，避免与上游应用同时运行。HUD 需要辅助功能权限，音频响应动画需要录屏与系统录音权限。
- 保留可选 Codex Bridge；安装说明与桥接脚本随包提供。Codex 集成和纸飞机指针依赖私有接口，兼容性受客户端及系统版本影响。

不承诺固定的 CPU 降幅；实际占用取决于音乐模式、动画、屏幕与机器配置。未覆盖所有 Mac 和 macOS 版本。
