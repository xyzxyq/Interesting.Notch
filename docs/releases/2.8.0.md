# interesting botch 2.8.0

基于 [TheBoredTeam/boring.notch](https://github.com/TheBoredTeam/boring.notch) 二次开发。本版本不是上游或 OpenAI 官方发行版。

## 更新内容

- 网易云音乐同步歌词接入，复用本地缓存、LRCLIB 和网易云歌词源；新增歌词候选预览、手动选择和 LRC 导入。
- 自动歌词选择加入正文文字校验和固定来源排序，避免拼音版本因先返回而被采用；升级自动缓存校验规则，保留手动选择。
- 修复播放器切换、暂停和退出时的歌词状态，增加音乐内容入场、退场与宽度衔接动画。
- 多个 Codex 提醒水滴合并并增大；处理完成后自动关闭提示面板，保留水滴返回动画。
- 改善 Codex 短暂状态变化的稳定性，并优化低电量、屏幕休眠和减少动态效果下的动画调度。

## 安装

下载 `interesting-botch-2.8.0-arm64.dmg`，打开后将 `interesting botch.app` 拖入 Applications。

- 仅提供 Apple Silicon（M 系列芯片）安装包，最低部署目标 macOS 14；未提供 Intel 安装包。
- 使用本地开发证书签名，**尚未经过 Apple Developer ID 公证**。首次打开可能被 macOS 阻止；核对来源后，使用系统提供的“仍要打开”入口。不要关闭系统保护。
- 更新前退出旧版；内部 bundle identifier 暂沿用上游，不建议与原版或本机开发版同时运行。
- HUD 需要辅助功能权限，音频强弱动效需要录屏与系统录音权限；授权对象应为实际安装路径中的应用。
- DMG 附带可选的 `Codex Bridge`、许可证、第三方归属及安装说明；桥接需要本机 Python 3 和已登录的 Codex。

## 歌词与兼容性

设置 → 媒体中选择“自动跟随正在播放的应用”，并开启“右侧滚动歌词”。网易云音乐 3.1.9 已在本机验证；QQ 音乐和酷狗专项适配暂缓。

歌词源不保证覆盖全部歌曲和版本。中文名称的外语歌曲可能需要手动选择；系统语言仅控制中文简繁，不自动翻译歌词。旧自动缓存会按新规则重新获取，手动保存版本保留。

## 验证

Release 构建及歌词、播放时钟、缓存、暂停状态、权限路径、更新源隔离和 Codex 桥接检查通过。安装包进行 SHA-256、DMG 只读挂载及应用签名校验。未在其他 Mac、全新用户账户或所有 macOS 版本上完成验证。
