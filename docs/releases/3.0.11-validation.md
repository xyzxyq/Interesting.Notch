# 3.0.11 发布验证

验证日期：2026-09-26。应用版本 3.0.11，build 311；Release 标识 `theboringteam.boringnotch`，arm64，最低 macOS 14。

## 应用与回归检查

- Release 完整构建通过，使用本地已解析的 Swift Package Manager 依赖。此前同一功能源码的 Debug 构建与签名 Preview 试用通过。
- `check-motion.py`：生产手势处理、真实 SwiftUI 滚动标题生命周期及 Lottie 播放策略检查通过；Lottie 检查使用库边界替身，不代表远程资源加载集成测试。
- `check-energy.py`、`check-music-idle.py`、`check-codex-polling.py`：低电量频谱帧率、暂停／恢复、屏幕休眠、计时器生命周期及旧查询结果丢弃通过。
- `check-native-bridge.py`：183 项投影对照和 16 项程序路径发现检查通过。实际打包的桥接二进制通过 `check-native-bridge-integration.py`，覆盖 IPC／HTTP、额度、隐私、鉴权、回答去重、重连及安装失败回滚。
- `BrandLocalizationChecks.py`、`check-release-updates.py`、`PackageReleaseDMGChecks.py` 通过。DMG 检查使用项目已有的 dmgbuild 虚拟环境；初次运行因 PATH 未包含该环境而停止，补正环境后通过。

## 实机范围

用户已确认 Preview 的自然收起和快速移入／移出时反向切换正常。燃料图标修复后，70.1 秒内的 15 个样本均有有效连接与额度，覆盖下一次自动刷新；显示从周剩余 8% 更新为 7%。

最终 DMG 以只读方式挂载，提取应用到独立目录。退出 Preview 后启动该提取副本，进程持续运行超过 30 秒，实际界面显示燃料图标及有效周剩余额度。没有替换 `/Applications` 中的应用。

真实触控板手势全集、所有播放器和长期额度可用性不在本轮验证范围内。没有严格的整机 CPU／能耗 A/B 测量；不以离屏基准或短时现场采样宣称固定能耗收益。

## 发布附件与签名

- DMG 中的版本、build、bundle ID、arm64 架构、最低系统版本及指向 `/Applications` 的链接均已核对。GPL 与第三方许可文件与源码逐字节一致。
- 应用沿用稳定本地开发证书，嵌套代码通过 `codesign --verify --deep --strict`；DMG 通过 `hdiutil verify`。安装包未经过 Apple Developer ID 公证。
- `appcast.xml` 指向 v3.0.11 的实际 DMG；版本、build、归档长度匹配，Sparkle 与独立 CryptoKit Ed25519 签名验证通过。
- 独立桥接 ZIP 包含原生可执行文件、安装器、构建脚本、Swift 源码和 Python 回退实现。应用内更新不会自动更新该桥接，升级说明单独列出安装命令。

## 发布后公开通道验证

GitHub 最新正式版已指向 v3.0.11，四个附件的远端 SHA-256 与本地文件全部一致。公开的 `releases/latest/download/appcast.xml` 返回 HTTP 200，内容与已验证的签名更新源逐字节一致。

使用独立目录中的 3.0.10 副本执行“检查更新 → 安装更新 → 安装并重启应用”：正确识别 3.0.11，从公开 Release 下载并完成安装，自动重启到 3.0.11 / build 311；运行路径与新 PID 已核对，燃料图标正常。更新后的主程序与最终 DMG 提取副本一致，严格签名验证通过。测试没有替换 `/Applications` 中的 3.0.10，结束后恢复原先的 Preview。
