# Interesting Notch 3.0.15 · 智能节能

新增可选的「智能节能」模式：在「设置 → 通用 → 智能节能」开启后，应用会根据电源与系统状态自动回退到基础功能，条件解除后恢复增强界面。**默认关闭，正常模式的动画帧率不变。**

## 自动切换规则

- 电池供电、系统低电量模式、严重或临界温度状态，任一条件成立即进入节能。
- 接电但暂停充电或已经充满，不会误判为电池供电；无电池或电池信息不可用也不会误触发电池条件。
- 所有条件解除，或手动关闭此开关后，自动恢复。复用现有电源事件和系统通知，没有增加轮询。

## 节能期间

保留原有音乐播放控制、封面、普通歌词、刘海展开、日历、电池状态和文件暂存等基础功能。

- 暂停火箭、尾焰、速度线、礼花、音乐边缘动效及紧凑歌词的增强绘制，恢复系统原指针。
- 完全隐藏 Codex 水滴、拉绳、小鱼、交互卡片与模型/额度栏；快捷键和预览不能绕过节能模式。此时请直接在 Codex 客户端处理交互请求。
- 同步暂停 Codex HTTP 状态轮询、音乐边缘音频采样及天气更新、定位和地名解析。
- 即使卡片正在展开或收起，也会立即取消过渡并释放窗口；保留待办、草稿、忽略记录和原有偏好。恢复后重新同步真实队列，不自动展开卡片或补播过时完成动画。

电源状态与恢复逻辑、卡片过渡中断、桥接旧响应取消和原有基础功能回归通过。**尚未进行物理拔插电源或电池续航对照，没有整机节电百分比结论。** 独立 Codex 桥接与 Codex 客户端继续运行。[使用说明与验证范围](https://github.com/xyzxyq/Interesting.Notch/blob/v3.0.15/docs/smart-energy.md)

## 安装与升级

支持 **Apple Silicon · macOS 14 及以上**。可在设置中检查更新，或下载安装包 `interesting-notch-3.0.15-arm64.dmg`。

**本次桥接与 3.0.14 相同，已安装 3.0.14 桥接的用户无需重装。** 首次安装或从更早桥接升级时，解压 `interesting-notch-3.0.15-codex-bridge.zip`，在解压目录执行：

```bash
python3 scripts/codex-notch-bridge-install.py --binary ./codex-notch-bridge
```

安装包沿用本地开发证书签名，**尚未经过 Apple Developer ID 公证**。首次打开被 macOS 阻止时，请核对下载来源后使用系统的「仍要打开」入口。附件提供 `SHA256SUMS.txt`，更新包另经 Ed25519 签名验证。
