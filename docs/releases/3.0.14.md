# Interesting Notch 3.0.14 · 交互提醒与后台效率

新增可选拉绳提醒、线条小鱼和可自定义快捷键，重做交互卡片的外观与操作，并减少无效后台工作。本次优化没有降低现有组件的动画帧率。

## 交互与外观

- **水滴或拉绳，自由选择**：在「设置 → 媒体 → Codex 火箭与交互提醒」切换提醒样式。拉绳提供上鱼了、经典灯钮、甜甜圈、星环、晶钻、漂浮水母、迷你飞碟、月亮摇篮、幸运扭蛋九款外观；点击展开，再次点击收起。
- **小鱼会回应等待状态**：银白轮廓搭配深色衬边，适应浅色与深色背景；加入上钩水花、甩尾、眼神联动、轮廓呼吸光和收线退场。等待时间只在队列事项确认解决后重置，查看或忽略提醒不会重置。
- **纯黑卡片与柔和倒角**：外缘使用渐变反光和阴影表达厚度，修正四角浅色残留、提醒与卡片间距及展开突现。拉绳使用自定义的类 Dock「神奇效果」；缩短最后一项提交确认后、开始收缩前的固定等待，保留展开时序。
- **完整键盘操作**：默认 ⌥⌘Return 打开卡片，数字选择并可重复按键取消；选中后 Return 回复，未选中时 Return 进入自定义输入，空输入再按 Return 退出，Shift+Return 换行。收起、忽略、切换提醒等操作可在「设置 → 快捷方式 → 快捷键自定义」调整，支持冲突提示、清除及恢复默认值。
- **提醒与对话信息更可靠**：修复桥接重连后“客户端等待回答但提醒未出现”、输入焦点切换及重复提交相关问题。每张卡片显示所属对话的模型和思考强度，快速模式增加静态发光标识；没有媒体内容时使用紧凑火箭。忽略仅隐藏本地提醒，不会代替回答或取消 Codex 任务。

## CPU 与内存

未开启锁屏显示时，应用在锁屏状态启动不再创建隐藏的绘制视图；去除重复无播放源状态发布，待办确认清空后释放卡片窗口，并减少桥接无效增量引发的历史扫描及轮廓临时缓冲区。

同机 Release 配对测量中，**仅在锁屏启动、禁止锁屏显示的场景**，主进程 CPU 从 **19.92% 降至 0.0102%**，进程内存 footprint 从 **84.4 MiB 降至 25.3 MiB**。100% CPU 表示一个逻辑核心；footprint 不等于 RSS。这不是解锁后可见动画的性能结论，也不能换算为整机省电或续航提升。解锁后的整体 CPU、实际展开/收起流畅度及长时间续航仍需进一步测量。[测量条件、原始数据与限制](https://github.com/xyzxyq/Interesting.Notch/blob/v3.0.14/docs/performance-2026-10-31-cpu.md)

## 安装与升级

支持 **Apple Silicon · macOS 14 或更新版本**。在设置中检查更新，或下载 `interesting-notch-3.0.14-arm64.dmg`，退出旧版后将应用拖入 Applications。

**Codex 用户请同时更新本次桥接附件。** 应用内更新不会升级独立桥接。下载并解压`interesting-notch-3.0.14-codex-bridge.zip`，在解压目录执行：

```bash
python3 scripts/codex-notch-bridge-install.py --binary ./codex-notch-bridge
```

安装包沿用本地开发证书签名，**尚未经过 Apple Developer ID 公证**。若首次打开被 macOS 阻止，请核对下载来源后使用系统的「仍要打开」入口，并可通过发布附件中的 `SHA256SUMS.txt` 核对文件。
