# Interesting Notch 3.1.3 · 效率与稳定性

- 保留水波视觉与动画帧率，消除音乐边缘效果的重复绘制，减少日历重复查询和 YouTube Music 重复封面请求。
- 检测到新版本时，设置中的软件更新区域显示简要更新内容；本版更新包也附带可在更新提示中查看的摘要。
- 修复多屏窗口观察者累积、隐藏屏幕窗口残留，以及 YouTube Music 退出、重连和迟到回调的生命周期问题。
- 修复暂存器图片转 PDF 遇到坏图时的崩溃，完善分享文件权限释放、缩略图缓存清理和 Quick Look 预览。
- 自定义动画地址增加输入校验，速度单位改为倍速；补齐颜色控件的可访问名称，显示器列表随系统变化刷新。

支持 **Apple Silicon · macOS 14 及以上**。可在应用内检查更新，或下载 `interesting-notch-3.1.3-arm64.dmg`。

本版没有降低动画帧率或增加后台轮询。针对性检查确认重复工作减少，但短时整包测试尚不能证明整体功耗降低或功耗不增加；长期续航和物理多屏验收仍未完成。

安装包沿用本地开发签名，尚未经过 Apple Developer ID 公证。自动更新包另有 Sparkle Ed25519 签名，附件提供 SHA-256 校验清单。

Codex 桥接与 3.1.2 相同，已安装兼容桥接的用户无需重装。首次安装请解压桥接附件并按仓库 README 操作。
