# Interesting Notch 3.1.0 发布验证

日期：2026-11-06（Asia/Shanghai）。版本 3.1.0，build 3100；Apple Silicon arm64，最低 macOS 14。

## 发布范围

- 沉浸专注、单句歌词投影、V 形玻璃内部渐隐、单道折射波、粒子消散、专注待机图标与计时。
- 专注音乐独占与独立播放器跟踪、Apple Music 封面严格匹配和异步曲目隔离。
- 从隔离源码目录构建；未将此前未采用的桥接连接复用、鱼线布局、音量去重及 ContentView 观察实验纳入本次发布。这些实验仍留在原工作区。
- 桥接源码、安装器与说明相对 v3.0.15 未变；沿用公开 3.0.15 桥接 ZIP，其 SHA-256 与 GitHub 资产摘要一致，仅修改附件名称。

## 已通过的检查

- Release 构建、本地开发签名及嵌套代码严格验证；bundle ID、3.1.0 / 3100、arm64、最低系统版本与许可文件核对。
- 64 种投影启用条件、歌词时间轴、分钟/小时边界、会话起点复用、关闭重开，以及小尺寸图标和紧凑计时渲染检查。
- Apple Music / Spotify / YouTube Music 的受控独立来源回归：其他媒体竞争、暂停、曲目/时钟/封面更新、11 个控制入口、退出和过期回调；普通模式媒体及暂停驻留回归。
- 封面目录严格匹配、异步 A/B 乱序、共享专辑、空数据、HTTP 错误和缩略图上限。发布检查发现 NSImage 的 Retina 表示会放大像素，已改为显式 NSBitmapImageRep，恢复 512 像素上限并重跑检查。
- 智能节能、视频轮询生命周期、音频采集需求与频谱暂停/恢复回归，以及受控 Codex 轮询和旧响应取消检查。
- 使用正式包的 Metal 库加载 GPU 检查：单道窄折射波、句末消散无残留、明暗背景字形、V 字内部遮罩提前透明、投影窗口鼠标穿透、隐私与释放。
- 最终 DMG 完整性、只读挂载、标准 `Interesting Notch.app` 与 `/Applications` 拖入布局。appcast 版本、build、精确下载地址、长度与 Ed25519 签名检查通过；使用既有密钥，Sparkle 与独立 CryptoKit 验签均通过。

## 未通过项与验证边界

完整 `check-codex-interaction.py` 在“水滴卡片宿主视图应在 AppKit autorelease 排空后释放”的断言失败。使用公开 v3.0.15 源码、同一工具链和环境重复运行，出现同一断言失败；延长等待和按事件排空 autorelease 也未解除。保留原严格断言，没有为了发布降低该检查要求。该现象的根因尚未确定，不能声称所有宿主视图释放检查通过。

新增专注的卡片抑制检查使用隔离测试副本，跳过上述已单独记录的旧版失败段，保留其余断言。检查通过：两种提醒样式在展开、显示、收起三个阶段开启专注均立即隐藏，保留待办和草稿，退出专注后可手动恢复；智能节能及其他交互断言亦通过。其结果与完整回归分开记录，没有向真实 Codex 请求发送回答。

本次使用本地开发证书签名，未经过 Apple Developer ID 公证。未覆盖 Intel、macOS 14/15 真机、多显示器所有组合、物理拔插电源与长期 CPU/GPU/内存；GPU 渲染检查不等同于整机节能证明或人工视觉验收。
