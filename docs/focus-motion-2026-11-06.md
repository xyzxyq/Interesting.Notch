# 持续投影与精灵光点（2026-11-06）

## 本轮行为

1. V 字玻璃投影放在歌词边界时间轴之外；音乐投影显示期间持续保留，歌词、间奏和换曲不会通过换句分支重新创建它。外接电源、音乐播放、锁屏/休眠、智能节能、岛体展开等原有门控保持。
2. 等待状态的三个粒子为不透明纯黑色，沿同一条上下错层的闭合曲线游动。每轮 7.2 秒，各错开 2.4 秒；每颗粒子轮流经过左、中、右位置，并在接近 V 字出光口时触发中性白色柔光回应。V 字边缘保持低幅度呼吸。所有循环由 Core Animation 驱动，不增加 SwiftUI 帧计时器。歌词消散粒子继续保持彩色。
3. 新句开始时，从出光口到歌词中心发出一次 0.62 秒的弧形扩散光脉冲：波前向下弯曲，以出光口为原点整体放大，两端渐隐；文字在前 0.18 秒显现。定位到句中不补播脉冲；同一句重复状态更新不会重启动画。V 字基础玻璃和呼吸不依赖脉冲的生命周期。
4. 消散粒子的基础半径从 0.6–1.2 点缩小到 0.35–0.70 点，采样网格从 3 点缩小到 2 点；保留 0.4 秒消散。颜色由来源网格单元确定，每颗粒子在整个漂移过程中保持自己的颜色，覆盖多种色相。描边保留 RGB，不再把彩色粒子转成灰白。正常阅读中的歌词仍保持中性玻璃字面。
5. 删除微光/水波样式枚举、Defaults 键引用及选择器。统一采用粒子投影；旧偏好中的样式值不再读取，无需用户重选，不删除其他用户设置。普通紧凑歌词和边缘动效的样式设置不受影响。

## 辅助功能与生命周期

减少动态效果时，V 字与光点静态显示，不运行飞行、呼吸、回应或换句光脉冲。减少透明度继续关闭原有玻璃材质并使用实色歌词。退出投影时拆除原生动画；已结束的光脉冲不保持最后一帧。

### 弧形脉冲补充验收

原生 Core Animation 预览检查了 0.18、0.32、0.46 秒三个时点：波前从出光口向下弯曲展开，端点渐隐，深浅背景均无直线光带。使用固定出光口锚点的整体缩放，删除原来的垂直位移及仅水平方向拉伸。弧线检查、持续 V 字呼吸、句中定位与减少动态效果检查通过；重新构建并启动了本地 Release 版本。此前短时 CPU 对照在弧形调整前完成，不代表弧形瞬态的 GPU 峰值测量。

### 黑色粒子换位补充验收

等待粒子改为纯黑、不透明的 CALayer，移除彩色渐变和透明度循环。三个粒子错开三分之一周期沿闭合曲线前进，每 2.4 秒轮换左、中、右三个位置；上行与下行使用不同高度，出光口的回应保持中性白光。歌词消散的彩色粒子不变。

生产组件回归检查了纯黑与不透明、每颗粒子访问三个不同位置、同一时点不占用同一位置、闭合路径，以及既有的弧形脉冲、减少动态效果和拆除。输出在 `build/focus-motion-20261106/spirit-checks.log`。原生预览对比浅色、灰色、深色背景并观察了两个运动时点；纯黑粒子在深色背景的对比度较低。本地 Release 构建、签名与启动通过。本次未重复测量 CPU/GPU 或整机功耗，沿用既有 Core Animation 调度和帧率上限。
