# 最后一条交互提交后的收起停顿

## 定位与改动

收起与展开原本共用 1.1704 秒时序；关闭先完整反向播放 0.5808 秒材质交接，期间卡片几何保持不变，再播放 0.5896 秒神奇收起。这段静止容易被感知为卡顿。

仅调整 CodexGenieTransition 的关闭时间映射：材质接管缩短为 0.12 秒，形变仍为 0.5896 秒，关闭总长 0.7096 秒。展开继续使用原先的 0.5808 秒材质渐变及 1.1704 秒总时长。反向操作将当前可见阶段映射到目标方向的时间轴，保留连续性。原生 Core Animation、采样点数量和后台轮询均未改变。回答仍需真实状态确认后才消失，没有把 HTTP 200 当作任务完成。

## 验证

- `scripts/CodexGenieChecks.swift`：原几何、分片连接、材质渐变，以及双方向阶段/时间往返、200 ms 内进入收缩的断言通过。
- `python3 scripts/check-codex-interaction.py --timing`：完整原生卡片回归通过；新增单条真实任务模型在状态确认后清空的检查，确认自动收起并完成清理。此隔离测试禁用网络回答，不代表向真实客户端发送了答案。
- 原生窗口材质中点：关闭约 61.8 ms 时快照呈现层透明度约 0.495；约 182.7 ms 时原生卡片已隐藏，快照正在形变。展开中点与原有时长保持不变。
- 回归覆盖快速反向、收起途中新提醒恢复、早期快捷键、选项/自定义输入、暂停、忽略、切换水滴。

## 性能边界

消除的是 460.8 ms 的固定几何静止等待，不是声称减少了等量 CPU 计算。修订前常规关闭快照准备约 69–79 ms；本次修订后完整关闭设置约 49–116 ms，新增最后一条状态清空用例为 116.9 ms。截图仍同步进行，没有证据宣称该成本已消除。试验 CALayer.render 耗时约 70.7 ms，未显示稳定收益，未用于产品。没有新增常驻计时器或降低帧率；本轮未重新测整机能耗。
